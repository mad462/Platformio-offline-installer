# PlatformIO Offline Installer v1.0.0

发布日期：2026-05-18

## 发布资产

- `PlatformIO_Offline_Installer.zip`

## 适用平台

- Windows

当前仅提供 `exe` 目录版发布包。用户下载 ZIP 后，解压并运行：

- `PlatformIO_Offline_Installer/PlatformIO_Offline_Installer.exe`

## 本版特性

- 合并 `offline-sdk-manager` 功能到统一安装器界面
- 启动后不再自动安装，改为标签页式操作
- 支持在同一窗口内完成：
  - 安装 PIO
  - 安装 SDK
  - 打包 SDK
  - 清理 SDK
- 支持 SDK 打包前依赖预检
- 支持使用 YAML 统一维护平台 / 框架 / 工具链依赖关系

## 内置 SDK

本发布包已内置以下常用 SDK，下载后可直接使用：

- `espressif32-54.03.20.sdk.7z`
- `espressif32-7.0.0.sdk.7z`

## 使用说明

1. 下载 `PlatformIO_Offline_Installer.zip`
2. 解压到本地目录
3. 运行 `PlatformIO_Offline_Installer.exe`
4. 先在 `安装 PIO` 标签页完成基础环境安装
5. 再在 `安装 SDK` 标签页导入内置 SDK

## 当前说明

- 推荐通过 GitHub Release 分发 `PlatformIO_Offline_Installer.zip`
- 不建议最终用户从源码自行构建
- 如果后续增加新的常用 SDK，优先放入 `resources/sdk`
